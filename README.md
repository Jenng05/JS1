# Rainy Days – JavaScript Version

## Description
An enhanced version of the Rainy Days e-commerce website, extended with Vanilla JavaScript to add dynamic functionality and improved user interaction.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Dynamic cart functionality
- Add to cart logic
- Interactive product pages
- Checkout validation
